# AI 服务

[English](ai.md) | **简体中文**

yovoice 可以选择接入大模型。配置 AI 服务后，右下角的“创作助手”面板可以用对话完成创作：新建和修改作品、写谱写词、改台词、配音色、发起语音、音乐或配乐生成，操作即时反映到界面。不配置也不影响其他功能。

## 添加服务

打开“设置 › AI 服务”。左侧列出已添加和可添加的服务，选中后在右侧直接填写：

| 服务 | 地址 | 密钥 |
| --- | --- | --- |
| DeepSeek、通义千问（百炼）、智谱 GLM、Kimi、豆包（火山方舟）、MiniMax、OpenAI、Anthropic、OpenRouter、OrcaRouter | 内置 | 需要；“从 … 获取 API 密钥”打开对应控制台 |
| Ollama、LM Studio | 默认本机（`127.0.0.1`），可修改 | 通常不需要 |
| 自定义 | 任意兼容地址 | 可选 |

OrcaRouter 提供免费模型，而且不用复制密钥：点“免费连接 OrcaRouter”（在设置里的 OrcaRouter 页），在浏览器登录 OrcaRouter 并同意授权。yovoice 在本机（`127.0.0.1`）接收密钥，自动添加服务、使用免费模型 `orcarouter/free` 并立即启用。免费模型高峰期可能限流，稍等一会儿重试或换一个模型即可。

自定义服务可选择三种协议：OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages，并填写模型列表路径（如 `/models`；服务没有模型列表时留空，直接填写模型名）。

填写模型名，或“同步模型列表”后从列表中点选；“添加服务”或“保存更改”后，“测试”会发送一条简短消息，检查地址、密钥和模型。第一个添加的服务自动启用；有多个服务时，打开想用那个的“用于 AI 功能”开关。已保存的密钥只显示掩码，可“更换密钥”或“清除密钥”。

## 数据去向

- 请求从本机直接发往你选择的服务，使用“设置 › 常规”中的代理，未配置代理时沿用系统代理；本机地址不走代理。
- 密钥保存在数据目录数据库 `yovoice.db` 的私有表中（权限仅限本人，`0600`），不会出现在发给界面的状态里；设置页只显示掩码，删除服务会同时删除密钥。
- 发送的内容是你写的需求，以及一段说明乐谱或歌词格式的固定提示词。错误信息在显示和写入日志前会去掉密钥。

## 助手面板

点标题栏的助手按钮或按 **⌘J / Ctrl+J** 打开面板。直接说要做什么——“新建一个编曲作品，写四小节钢琴旋律”“给这个故事的角色逐个配音色”“生成这段旁白”——助手就会在应用里动手：作品建好即打开，写内容时编辑器即时更新，生成也走应用现有的流程。工具调用以卡片形式出现在对话里，生成好的音频可直接播放。一轮进行中再发的消息会排队；“新对话”开始新话题，历史记录保留在面板里。

每条消息都附带当前页面、打开的作品和界面语言，助手据此找到操作对象。它没有删除、下载模型、导入导出和改设置的工具；缺模型时会告诉你去哪里安装。

## AI 写谱与写词

在编曲或音乐作品顶部的一句话栏写下需求，会作为一条消息进入同一对话并自动打开面板：助手读取作品，写出编曲（与手写乐谱同一套校验，不通过会自行修正）或风格、歌词与标题，直接写进作品；想改就在面板里继续说。模型越强，编曲越好；较小的本地模型可能通不过检查。

## 限制

- 同一时间只运行一轮对话，可随时停止；单轮默认 10 分钟，可在设置中调整。面板保留最近 200 条消息，重启后仍在。
- 浏览器预览模拟对话流程，真实调用模型需要桌面应用。
- 尚未在每个内置服务上逐一实测；服务拒绝请求时，错误信息会显示 HTTP 状态和原因。
