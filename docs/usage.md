# Usage index / 使用导航

English · 简体中文

This index maps the non-realtime speaker-profile workflows to their product scenarios and authoritative parameter guides. Speaker profiles are private local records, not proof of a person's identity. They store a 256-dimensional embedding outside `state.json`; normal status and voice-library responses do not include it.

本页将非实时声纹档案流程映射到产品场景与参数权威来源。声纹档案是私有本地记录，不证明现实身份；它将 256 维特征保存在 `state.json` 之外，普通状态和声音库响应不会包含该特征。

Local `YOVOICE_SPEAKER_*` configuration is documented in [development](development.md#speaker-recognition-development). | A new public profile JSON is returned. `runtime_not_configured`, invalid audio, capacity and feature-version errors do not create a profile. / 返回新档案；配置、音频、容量或版本错误不写入档案。 |

| USG-SPEAKER-MAC-VALIDATION | SCN-UI-22 | Build and open the local Finder-launchable validation bundle that uses the original WKWebView host and fixed local recognition assets. | Run `scripts/desktop/build-speaker-validation-macos.sh`, then `scripts/desktop/smoke-speaker-validation-macos.sh`; the build stores a versioned `<app>.receipt.json` sidecar beside the signed bundle. If that fails, manually unlock the Mac and return to a visible desktop session before a newly authorized run. It is a local verification build, not a signed, notarized, or released application. System microphone recording and human TTS listening remain separately reported. / 依次执行构建和冒烟脚本；构建会在已签名 App 同级保存带版本的 `<app>.receipt.json` 凭据，将源码候选与最终 App 树、宿主、服务和 Web 资源绑定；冒烟会在启动宿主前核对该凭据。验证包使用独立资料目录和 bundle ID，只包装已安装的 FFmpeg 而不修改它，也不会下载 TTS 运行环境或模型。凭据缺失或不匹配时不会启动宿主。DEBUG 冒烟脚本开始前，宿主会请求一次可见桌面显示，并在最多 10 秒内检查窗口、WebView 尺寸和文档可见性；失败时先手动解锁 Mac 并回到可见桌面会话，再取得新的运行授权。 本地识别配置被拒绝时，公开运行状态保持未配置，服务日志仅记录脱敏后的字段与原因分类；它是本地验证构建，不是签名、公证或发行包。系统麦克风录音和人工 TTS 听测单独报告。 |
