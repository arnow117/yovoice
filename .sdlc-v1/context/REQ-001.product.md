# REQ-001 — 非实时声纹识别与参考音色绑定原型

## 方向来源与问题

用户在 yovoice 源码报告及声纹扩展可行性讨论后明确要求：fork 一个做做看，并摸清项目每次迭代后如何验证。首版沿用已说明的非实时 CLI / 自托管 HTTP API 登记、识别、音色绑定范围，不修改桌面 UI。

长期产品目标文档：`none`；工程事实引用 `.sdlc-v1/project.md`。仓库 `arnow117/yovoice`，初始上游快照 `2401e134d3b0ecd0f25f52a8e1d1e4527159dfde`。已有开发/API/模型指南约束兼容性，不构成生产声纹产品的需求来源。

当前声音库只保存 TTS 参考录音，调用方需要自己选择音色，无法登记声音身份或判断新录音更像哪位已登记者。本原型验证“登记声音 → 识别另一段录音 → 明确选择绑定参考声音 → 现有 TTS 合成”的可复现链路。

## 用户、结果与成功指标

目标用户是本地开发者和自托管 API 调用方；同一数据目录属于一个操作者，持有现有 API Token 的调用方使用同一档案库。没有租户、员工账号或现实身份认证含义。

| 结果 | 当前基线 | 本次目标与观测方式 |
|---|---|---|
| 登记/识别可调用 | 无声纹档案或识别接口 | CLI 和 HTTP 都能完成登记、列表、识别、删除及按档案选择参考音色；逐场景断言结果和持久化状态 |
| 匹配决策可解释 | 无 | 输出 matched / unknown / ambiguous、原始相似度及有限候选；阈值和分差可追溯，不显示未经校准的概率 |
| 真实模型可复现 | 无质量基线 | 固定模型、输入样本、参数及实现版本实际提取特征并识别，保存每条样本的预期/实际、相似度、耗时和失效原因 |
| 音色绑定有效 | 只有人工 voiceId 选择 | 使用档案选中的参考音频进入现有克隆 TTS；确定性测试验证选择与参数，实模生成和听测分别记录 |
| 迭代验证清楚 | 上游已有分层检查，未覆盖识别质量 | 给出按改动范围选择核心、API、Web、原生、打包、真实模型检查的说明，列出未执行/Skip/证据不足部分 |

原型的质量承诺是有限样本的真实结果，不能据此宣称生产准确率、身份真实性或可用作访问控制。首跑结果成为后续同配置比较的基线；没有实模观察时只能报告功能测试通过、质量未验证。

观察窗口默认从首次本地交付起 7 天，观察者为当前用户与开发者：收集误匹配、unknown/ambiguous 比例、处理时延、取消失败和失效绑定。报告附模型/样本/参数/版本；新的产品范围或真实用户反馈另建 Requirement，不把试用结果写成生产承诺。

## 范围与默认取舍

- 范围内：单段、单人录音；独立声音档案登记、列表/删除；1:N 识别；匹配阈值与候选分差；登记时可选绑定已有参考 voiceId；CLI 与已鉴权 HTTP API；按档案选择现有克隆 TTS 的参考输入。
- 本地操作者配置识别模型、运行程序、有限超时和决策参数。首版不自动安装识别模型，配置缺失明确失败；远程请求不能选择服务器路径、模型文件或执行程序。
- 音频默认边界沿用现有参考声音：输入不超过 20 MiB、解码时长 1–60 秒（含边界），格式限已有本地解码器支持的类型。识别不得静默截短、拼接或自动拆分多人录音。
- CLI 可读取操作者明确提供的本地文件或已有 voiceId；HTTP 只能上传音频或引用本服务已有 voiceId。来源缺失、两种来源同时提供或引用不存在均失败。
- 范围外：桌面 UI、MCP 新工具、多租户、实时/流式、多人分段、转写、现实姓名核验、防伪/活体检测、自动学习、档案合并、模型自动迁移、TTS 训练、云端声纹服务。
- 未提供重命名、补充多录音或编辑已有档案的流程；需更换登记音频/模型/绑定时删除并重新登记。这样可保持首版的数据与取消行为有界。
- 少量有明确使用许可的官方示例录音用于模型和接口 smoke；用户素材及面向人群的评估不从原型授权中自动推定。

## 术语、规则与不变量

| 术语 | 含义 |
|---|---|
| 声音档案 / profileId | 操作者登记的声音特征及元数据；ID 独立于 voiceId、字幕 speakerId 和模型预置 speaker；显示标签不证明现实姓名 |
| 登记音频 | 用于建立一个档案的单人录音；同一段音频重复登记是显式创建新档案，不自动合并或学习 |
| 查询音频 | 本次用于识别的录音；识别只读，不改档案、绑定或声音库 |
| 绑定参考声音 | 可选的现有 voiceId；登记音频不必与 TTS 参考声音相同，也不自动替调用方决定绑定 |
| 原始相似度 | 当前识别模型/评分规则下用于排序的数值，较高表示更相似；不能作为跨模型概率比较 |
| 特征版本 | 足以区分模型及预处理/评分规则的标识；具体构成由 Plan 决定，旧特征不与不兼容新特征混比 |

1. **登记与数据完整性**：成功后才出现可查询档案，返回 profileId、标签、特征版本及可选绑定。标签可省略并以 ID 展示；提供时去掉首尾空白，长度为 1–100 个 Unicode 字符，允许重名。档案列表与声纹相关输出不暴露向量、服务器路径或执行配置，新增特征也不能经已有普通状态接口泄露。每次成功登记创建一个完整档案；无有效语音、解码失败、模型失败、无效特征或保存失败均不留下半成品。
2. **识别决策**：先验证输入/配置及特征兼容性。空库返回 unknown，原因是无档案；非空库按分数排序，最佳分数低于阈值 T 时 unknown；最佳达到 T，但前两名并列或分差小于 M 时 ambiguous；其他情况 matched。只有一个候选时不需要第二名；T/M 必须是有限且合法的当前模型参数，M 大于 0。
3. **可观察结果**：matched 才返回确定的 profileId；unknown/ambiguous 不返回已选身份，允许返回数量受限、按分数排序的候选。响应给出使用的模型/特征版本、T/M 和原始分数；空库无分数。相等于 T 可通过绝对阈值，相等于 M 可通过分差要求，并列仍 ambiguous。
4. **持久化与删除**：档案在同一数据目录的 CLI/API 和重启后可用。删除成功后新查询不能匹配该档案，新合成不能按它选择音色，恢复备份不能复活已删档案；删除不存在的 ID 保持已删除结果。删除仅移除档案及其特征，不删除已有参考 WAV、TTS 历史或作品，不承诺硬盘取证级安全擦除或操作者外部备份擦除。
5. **音色选择与兼容性**：按档案合成需明确提供 profileId、目标文本、现有克隆模型及所需设置，解析其绑定 voiceId 和已保存参考原文。绑定提供参考声音/原文，调用方仍控制文本、模型、情绪、速度等参数；同时另传冲突的参考 voiceId/文件/原文时拒绝。绑定缺失、已失效或模型不支持克隆时明确失败，不回退随机音色。unknown/ambiguous 不自动合成。
6. **失败与并发**：每次识别读取一个完整档案集合，登记/删除不能造成半更新；与删除并行且已开始的识别可以基于开始时的快照返回候选，后续按档案合成必须重新检查存在及绑定。昂贵操作沿用有界单任务行为，繁忙时立即报错，不无限排队；取消/超时在短原子提交阶段接受点之前发生时不能迟到写入；接受点是编辑锁内最后一次取消检查通过并进入有界落盘阶段。此后落盘成功仍返回成功，不通过取消撤销它，也不把已保存档案返回为取消。登记不承诺网络重试去重；响应丢失时先列表确认，不自动重试制造重复身份。
7. **安全与资料保留**：HTTP 继承现有 Bearer 鉴权及拒绝带 Origin 请求的规则；每个入口在读取音频或运行模型前鉴权。声纹只在操作者的数据目录中保留至删除，不自动上传、自动学习或用于授权。临时查询音频在成功、失败、取消后清理；新功能日志不包含向量、原始音频、Token 或完整服务器路径。
8. **旧功能保持**：现有 voiceId、字幕 speakerId、预置 speaker、TTS 输入语义及声音库管理仍成立。不用新档案 ID 替代旧字段；不传 profileId 的旧 CLI/API 请求按原流程执行。

## Given / When / Then 验收场景

以下分数只用于验证业务分支，不预选评分算法或真实模型默认参数。例子统一 T=0.80、M=0.05；真实模型参数由 Plan 固定并说明依据。

| ID | Given | When | Then |
|---|---|---|---|
| SCN-01 | 合法单人音频、可用识别配置、可选已存在绑定声音 | 通过 CLI 或 HTTP 登记并列表 | 返回独立 profileId；标签/版本/绑定一致，列表无向量；重启后仍存在 |
| SCN-02 | 两档案 A/B，查询分数 A=0.91、B=0.82 | 识别 | matched A，返回分数与所用 T/M/版本；识别后档案库未变化 |
| SCN-03 | 有效配置/输入，档案库为空 | 识别 | unknown，原因无档案，候选为空，无已选 profileId |
| SCN-04 | 最佳分数 0.79 | 识别 | unknown；不能返回 matched 或触发合成 |
| SCN-05 | A=0.86、B=0.84，或二者同分 | 识别 | ambiguous，返回有限候选，无已选身份，不按排序第一名自动合成 |
| SCN-06 | 只有 A=0.80，或 A=0.90、B=0.85 | 识别 | matched A；验证等于 T/M 的边界（评分精度由 Plan 明确） |
| SCN-07 | 空文件、静音/无有效语音、损坏音频、超过 20 MiB、时长不足 1 秒或超过 60 秒；登记标签为空白或超过 100 字符 | 登记或识别 | 有可恢复原因的错误，不截短接受；登记不新增档案，查询不写声音库 |
| SCN-08 | 配置缺失/执行失败/无效特征，或旧档案特征版本与当前配置不兼容 | 登记或识别 | 明确配置/模型/兼容性错误，不能伪装 unknown 或跳过不兼容档案声称完成 |
| SCN-09 | 已登记 A 并绑定 V，A 另有显示标签 | 删除 A，再列表/识别/按 A 合成；重复删除 | A 不再可用、重复删除保持已删除；V 的 WAV 和旧生成历史保持原状；重启不复活 A |
| SCN-10 | A 绑定 V，V 有参考原文，选择支持克隆的现有 TTS 模型 | 明确用 A 合成调用方提供的正文/情绪 | 实际输入选择 V 和其参考原文，正文/情绪保持调用方设置；返回现有格式的生成结果 |
| SCN-11 | 档案无绑定、V 已被删除、profileId 不存在、冲突参考输入或选择仅支持预置音色的模型 | 按档案合成 | 明确错误，不回退其他声音，不产生错误音色输出 |
| SCN-12 | 错误/缺失 Token，或请求含 Origin、服务器路径/执行配置 | 调用新的远程入口 | 认证/输入错误；不读取任意路径，不启动模型，不修改档案 |
| SCN-13 | 登记正在提取特征，尚未提交 | 在提交接受点之前 CLI 取消、HTTP 上下文取消或达到配置超时 | 操作终止并清理临时输入，稍后也不会出现该档案；接受点之后落盘成功时按已成功结果处理 |
| SCN-14 | 一次昂贵识别/登记正在运行；或识别与删除同一档案重叠 | 再提交昂贵任务，或完成删除后再识别/合成 | 前者明确 busy；后者使用完整快照，新操作不能使用已删档案，既有历史不受损 |
| SCN-15 | 已登记 A；再次提供同音频或同标签，或前次成功响应丢失 | 列表确认后明确再登记 | 创建另一个独立 ID，不覆写 A、不自动合并；不把网络重试当作去重；相似候选可按分差返回 ambiguous |
| SCN-16 | 原有声音库、字幕、生成参数及未含 profileId 的旧请求 | 启用原型后调用旧功能 | 旧 ID 和输入语义保持；必要上游回归通过 |

## 体验与非功能要求

- CLI 操作阻塞至有限终态，成功结果可机器读取；进度/诊断不混入结果。匹配拒绝是正常识别结果，输入/配置/执行/保存错误是失败；调用方可以据此分别恢复。
- HTTP 返回与 CLI 相同的业务含义；状态码、字段、错误码、命令名称及超时数值由 Plan 明确，不要求新增异步任务系统或桌面入口。
- 识别只处理已声明的单人输入；首版用近静音检查及提取器准备条件拒绝已知无效输入，不能保证排除任意噪声/音乐，不保证自动检测多人或伪造音频；已知不符合单人要求的素材不能作为准确率验收样本。
- 请求必须可取消、有有限输入和超时；错误反馈说明需要换输入、修配置、重新登记、选择绑定或等待繁忙操作结束。具体性能预算由 Plan 按选定模型/设备记录，首版不承诺实时。持久化与删除承诺覆盖正常重启/进程退出及内部备份；断电/系统崩溃的文件系统耐久性不在首版承诺内。
- 不改变现有数据目录的进程互斥和 TTS 取消语义；运行状态、版本、时长、操作终态可诊断，敏感音频和特征不可通过普通列表/状态接口泄露。

## 真实模型与迭代验证验收

1. **功能正确性**：SCN-01 至 SCN-16 由确定性业务断言覆盖，CLI/API 的同义操作结果一致；假提取器或人工分数只验证分支、取消及失败行为，不计入模型质量。
2. **最小真实识别 smoke**：优先使用许可明确的官方样本，至少两个不同已登记者、每人一段不同查询录音及一个未登记者查询；登记音频自身回放或同文件复制不充当独立查询。若仅有一个样本/裁剪片段，只可报告对应 smoke，不能声称满足此范围。
3. **质量观察**：固定配置后记录已登记者的正确匹配/错认/拒绝计数，未登记者的误接受计数及每条耗时；展示样本级结果和分母。小样本无生产准确率结论；没有真实样本或无法运行时标记未验证并保留原因，不能以模拟结果代替。
4. **质量判断**：最小 smoke 的预期是两个独立同人查询分别 matched 正确档案、未登记者不被 matched；若不满足，保持真实质量未通过并报告差异。不可仅为同一验收样本反复调阈值后隐去失败；参数调整需要新独立查询或明确标记为样本调试。
5. **TTS 链路**：确定性验证选择的参考音频、原文和目标设置；选择许可允许的模型/目标设备实模生成后听测“能听懂目标文本、无明显截断/静音、参考音色没有明显串换”，保留 WAV 和人工结论。缺模型/设备时单列未验证，假引擎 WAV 不证明音质。
6. **每轮验证说明**：核心变更执行现有格式/vet/race及新功能回归；CLI/API 跑受影响旅程及鉴权/错误/取消；UI、原生或打包相关变更按 project.md 追加相应检查；模型/预处理/阈值变化重跑固定实模样本。证据绑定被测 commit、配置、工具版本、产物和退出结果，列出 Skip、未运行与证据不足。

## 依赖、未决项与产品决策

- 产品行为与本次范围已收敛，可进入 Plan；以上原型默认值来自当前输入边界和最小演示目标，不表示已获生产部署或用户素材采集授权。
- Plan 需要确定：识别模型/许可与可复用运行入口；特征版本定义、评分尺度、T/M 默认依据、候选上限、音频有效语音判断；CLI/HTTP 契约及冲突语义；安全持久化/删除/备份和取消提交规则；固定测试样本、实际环境、有限超时及验证产物位置。
- 尚缺的是工程与验证准备：真实模型资产、许可明确的独立查询样本、识别质量 baseline 及 TTS 听测证据。没有这些不能宣布真实质量验收通过，但不阻塞在有界范围内制定工程方案。
- 如选定模型必须联网上传音频、无法接受当前输入边界、需要自动采集用户素材、修改桌面 UI 或引入租户权限，应回到本产品上下文处理范围决定，不能作为普通实现细节追加。
